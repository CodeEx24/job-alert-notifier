Watch a search

On OnlineJobs.ph, Glassdoor, LinkedIn, or Upwork, run a job search with whatever filters you want, then paste that results page's URL below — for LinkedIn, either the address-bar URL or a "Jobs" search-page URL both work, it's converted automatically. OnlineJobs.ph checks happen fully in the background — Glassdoor, LinkedIn, and Upwork all need you to keep a tab of that search open (signed in, for Glassdoor and LinkedIn), since all three block background checks (bot protection). Tracking more than one search on the same site? Keep a separate tab open for each one — with multiple tabs of the same site open and none matching a watch exactly, it can't safely tell which tab belongs to which search.
